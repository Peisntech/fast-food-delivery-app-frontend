# 🍔 PeisinTech Food - Fast Food Delivery Platform this is my frontend test 

**Kikoni Door to Door Fast Foods** - A modern, fast, and responsive food delivery frontend delivering delicious meals straight to your doorstep in Kampala.
### 🚀 Tech Stack

- **Core:** React 18 + TypeScript 5
- **Build Tool:** Vite - Lightning fast HMR
- **Styling:** Inline CSS + SCSS + Custom CSS (utility-first)
- **Code Quality:**TypeScript, Fully Typed Components
- **Architecture:** Component-based, Reusable UI

### ✨ Features

- 🏠 Modern landing with hero, menu, and offers
- 🛒 Product listing with categories (Burgers, Pizza, Drinks)
- 🎨 80+ Reusable Components (ButtonPrimary, CardCategory, NavBar, etc.)
- 📱 Fully Responsive - Mobile, Tablet, Desktop
- ⚡ Optimized Performance with Vite
- 🧩 Clean Code

### 🛠️ Quick Start

✅### bash
Clone the repo
git clone https://github.com/Peisintech/fast-food-delivery-app-frontend.git

💥# Go to project
cd fast-food-delivery-app-frontend

💥# Install dependencies
npm install

💥# Run dev server
npm run dev

💥# Build for production
npm run build

Open `http://localhost:5173` - You will see Kikoni Door to Door Fast Foods 🍕
